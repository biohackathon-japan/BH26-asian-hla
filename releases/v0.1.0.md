# DōgoHLA and AsianPGR v0.1.0

This release accompanies *Evaluating Asian-specific pangenomes for HLA typing*.
It establishes the BioHackathon repository as the release home for DōgoHLA and
AsianPGR.

## DōgoHLA

DōgoHLA is a population-specific, pangenome-based method for diploid HLA sequence
reconstruction. Its population haplotypes guide read collection and graph-based
structural inference. The frozen method combines these inputs with repaired
phase-block linkage and guarded reconstruction of supported noncoding indels.
SpecHLA components supply alignment, small-variant calling and initial
reconstruction, with their MIT licence and citation retained.

The source archive includes code, tests, original preparation/job scripts and
frozen development controls. It preserves the prepared DDBJ execution layout;
see the README for environment paths, dependencies and reference preparation.
The eight-donor development comparison recovered 57/128 exact whole genes versus
36/128 for native SpecHLA and reduced global edit distance by 22.8%. The release
excludes interim outcomes from the ongoing additional-donor evaluation.

## AsianPGR

The graph represents 754 MHC haplotype entries, including Asian and Arab cohorts,
with GRCh38 and CHM13 reference paths. The archive contains clipped and full GBZ,
matching Giraffe short-read indexes, snarl indexes, a graph-derived VCF and
source/build provenance. The clipped graph contains 417,896 nodes, 579,137 edges
and 5,885,602 sequence bases. Original graph filenames are preserved.

## Analysis archive

`BH26-HLA-v0.1.0-analysis.tar.gz` contains the frozen source snapshot and compact
result tables behind the panel, structural and typing comparisons. It retains
original relative paths, donor manifests and original checksums. Downloaded
literature, raw IPD databases, live validation outputs and large external reads
or assemblies are excluded. External inputs and restoration instructions remain
identified in the source manifests.

## Checks

All 15 retrieved graph files matched remote SHA256 checksums. The DōgoHLA source
passes 41 regression tests after fetching the pinned nomenclature inputs.
Archive-member checksums and the release `SHA256SUMS` file support verification.
The release packaging leaves inference code unchanged; documentation describes
the public method and resource names. Original source hashes and snapshot
identity are in `source-snapshot.json`.

The manuscript PDF was rebuilt with its author fields intentionally empty.
The automatic author-requiring PDF workflow is skipped for this release commit.
