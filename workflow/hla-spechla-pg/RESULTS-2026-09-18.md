# AsianHLA–SpecHLA development results — 18 September 2026

These are development experiments, not locked validation. All eight donors are
in fold 0: HG00706, HG02155, HG03239, HG03742, HG03804, NA18620, NA19087, NA21093.
Their panel haplotypes and pedigree relatives are excluded from training inputs.
The original A-arm read bins, BAM, small-variant calls and low-depth mask are
frozen for phase comparisons. Naming databases are held fixed unless explicitly
identified as a designation-window control.

## Direct comparison with the saved native SpecHLA runs

Rescoring the same eight native SpecHLA 1.0.12 outputs with the identical global
whole-gene metric gives **36/128 exact genes**, versus **57/128** for the final
candidate. Total edit distance falls from **97,965 to 75,634** (22.8% lower),
and two-field genotype accuracy rises from **61/63 to 62/63**. Edit distance
improves in all eight donors; exact-gene counts improve in six and tie in two.

The earlier 43/128 control is **already panel-augmented** (A-replay), not native
SpecHLA. The 36/128 native figure also differs from the slide's 41/128 because
the slide used infix matching, whereas this audit requires global exactness.
Native output files were validated and hashed; their legacy COMPLETE markers
do not provide the full provenance checks of the new experiment runner. This
is a direct retrospective pilot comparison, not a new independent benchmark.

Evidence: [native comparison and output hashes](results/native-rescore-20260918/comparison.json)
and [native per-gene scores](results/native-rescore-20260918/native_gene_scores.tsv).

## Phase repair and database comparison

All 56 donor/arm runs completed and passed output/configuration verification.
The primary sequence endpoint below requires an exact **global whole-gene**
match, with N counted as a mismatch and the two haplotypes optimally assigned.
It is stricter than the old infix metric used in the slides; the two series
must not be combined. A-replay also uses the shared deterministic eigensolver
initialisation, so it is a new paired control rather than an assertion of
byte-identical replay of a previously stochastic run.

| Phase method | Exact genes / 128 | Total global edit distance | Two-field genotypes / 63 |
|---|---:|---:|---:|
| Original phase logic, native database | 43 | 77,384 | 61 |
| Maximum/HSP repair only, native database | 45 | 77,159 | 61 |
| Maximum/HSP repair only, IPD 3.65 | 44 | 77,255 | 60 |
| Maximum/HSP repair only, IPD 3.65 + panel | 42 | 77,253 | 60 |
| Full phase repair, native database | 53 | 76,908 | 62 |
| Full phase repair, IPD 3.65 | 57 | 76,924 | 62 |
| Full phase repair, IPD 3.65 + panel | 57 | 77,006 | 62 |

The full repair groups the two complementary haplotype scores by phase
alternative. Upstream's `x == y` condition mixes the parallel and crossed
alternatives; `x == 0` follows the actual `link_type[x][y]` layout. A regression
test executes the patched upstream method with distinct scores for all four
pairings, proving that the resulting edges are `14+23` and `32+41`, rather than
`14+41` and `23+32`.

The panel **does not add a measurable phase benefit here**. The most promising
phase candidate is the complete repair with IPD 3.65; the binning input remains
AsianHLA-panel augmented. G-group correctness remains 62/63; three-field
correctness rises from 55/62 in A-replay to 57/62 in the updated-IPD full repair.
The mask contains the same 15,358 N bases in every phase arm.

  Giraffe takes approximately **1.1–2.1 seconds per locus** for 613–1,380 pairs

## Structural reconstruction: the first prototype and its failure mode

A first conservative homozygous-allele overlay reduced DRB1 global errors from
965 to 318 in HG02155 and from 1,269 to 623 in HG03804. It left the uncertain
HG00706 call unchanged; two-field calls stayed correct in this three-donor
smoke test. None of these DRB1 genes became globally exact.

Expanding to all eight donors revealed a failure: replacing whole graph allele
blocks also overwrites embedded coding SNPs. Two large blocks produced identical
coding haplotypes where read phasing had supported different alleles. Native
DRB1 annotation additionally truncates its query at a fixed 11-kb coordinate,
which can miss exons after long insertions. Sequence edit distance improved,
but two-field correctness fell from 62/63 to 60/63. **That whole-block prototype
is not the selected method.** The failed experiment is retained in
[hybrid-v2](results/experiments/20260918-hybrid-v2/paired-score/summary.tsv).

The revised implementation uses affine-gap alignment to decompose each supported
graph allele into primitive long indels, excludes those overlapping annotated coding exons, and preserves
read-phased SNPs and small indels. It validates REF, interval boundaries and
unique flanks before applying either haplotype change. Parent graph genotype
confidence is inherited; it is not an independent confidence estimate for each
primitive. A narrow experiment-local annotation patch removes the fixed DRB1
11-kb crop while keeping the same database and ranking logic. Naming-only
controls retain identical sequences to distinguish designation from inference.
Unit-cost alignment was first tested but fragmented these repeat-associated
insertions into small gaps; that negative intermediate is retained as hybrid-v3.
The affine implementation is hybrid-v4.

## Selected development candidate: full repair + IPD 3.65 + guarded graph indels

The final **hybrid-v4** run completed all eight Slurm array tasks successfully,
including all 32 reconstruction/naming-control runs. The revised graph step
reduces **76,924 → 75,634 total global edits**, with **57/128 exact genes** and
**62/63 correct two-field genotypes** unchanged relative to repaired phasing
with IPD 3.65. Naming-only controls have identical sequence scores and preserve
the same two-field calls, so the 1,290-edit reduction comes from reconstruction.

| DRB1 donor | Full repair + IPD 3.65 | + guarded graph indel | Decision |
|---|---:|---:|---|
| HG02155 | 965 edits | 321 edits | Applied supported noncoding insertion |
| HG03804 | 1,269 edits | 623 edits | Applied supported noncoding insertion |

HG00706 and other low-confidence/heterozygous calls remain unchanged. Large
calls in HG03239 and NA21093 are withheld because at least one reference
boundary cannot be mapped safely onto the reconstructed haplotypes. No complete
DRB1 sequence becomes exact in this pilot. The unrecovered large structural
regions remain a major source of error.

Evidence: [final paired summary](results/experiments/20260918-hybrid-v4/paired-score/summary.tsv),

and [exact tested code snapshot](results/experiments/20260918-hybrid-v4/code/).
The current source passes **31 local regression/integrity tests**; both batch
scripts pass shell syntax validation. Inference uses no assembly truth. These
