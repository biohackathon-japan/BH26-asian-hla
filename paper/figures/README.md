# Manuscript figures

Figures 1–3 and supplementary Figure S1 are supplied as vector PDF and SVG,
with PNG previews. The manuscript embeds the PDFs. Vector versions preserve
all graph nodes, edges and labels when zoomed.

Regenerate from frozen data with `python3 scripts/plot_graph_figure.py` and
`python3 scripts/plot_paper.py` from the repository root. Graph decomposition
provenance and local regeneration instructions are in `../data/graph/README.md`.
Presentation derivatives of Figure 1 are in `slide_panels/` as PDF and SVG.
